### Key gotchas discovered (2026-05-19)

- **Invoice export**: requires `?userLocale=en-US` query param; without it returns 400
- **Invoice item type**: must be a name string matching workspace settings (e.g., `"NEW DEFAULT"`), not an ID; sending an ID returns 404
- **Invoice payment field**: `paymentDate` (not `date`)
- **Invoice status patch field**: `invoiceStatus` (not `status`)
- **Expense create/update**: `multipart/form-data` required, not JSON
- **Time off request dates**: `YYYY-MM-DD` format (not RFC3339) in `timeOffPeriod.period.{start,end}`
- **Time off policy `approve`**: must be an object `{requiresApproval: bool}`, not a boolean
- **Time off policy PATCH**: uses `status: "ARCHIVED"` to archive
- **Webhook create**: uses `webhookEvent` field (not `event`)
- **Shared report create**: uses `type` field (not `reportType`); DETAILED type requires `filter.detailedFilter` object
- **GET /shared-reports/{id}**: returns JSON report DATA (time entry totals), not the shared report entity
- **Audit log base URL**: live API-key probing found `https://auditlog-api.api.clockify.me/v1`, but audit logs remain unsupported for generated add-ons until official add-on-auth evidence exists.
- **Scheduling**: requires paid plan upgrade; workspace free tier returns 500 on assignment create
- **Approval create**: requires `period` + `periodStart` (not `dateRangeStart`/`dateRangeEnd`)
- **GET scheduling totals**: requires `start` (not `dateRangeStart`) query param
