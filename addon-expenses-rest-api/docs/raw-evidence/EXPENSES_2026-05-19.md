## Key Gotchas

- **Expense create/update uses `multipart/form-data` not `application/json`** — sending JSON returns `Content-Type 'application/json' is not supported`
- **Required multipart fields for create**: `userId`, `amount`, `date` (RFC3339), `categoryId`
- **PUT requires `changeFields` multipart field** — comma-separated list of changed fields (e.g., `NOTES`, `AMOUNT`, `CATEGORY`, `DATE`, `USER`, `PROJECT`, `TASK`, `BILLABLE`)
- **Expense GET list wraps in `{expenses: [...], ...}` envelope** — not a bare array
- **Category PATCH uses `archived` boolean field** not a status string
